# Abonnement de démonstration (contenus libres)

Playlist M3U pour montrer Graal sans contenu protégé : chaînes diffusées gratuitement et officiellement par leurs éditeurs (France 24, Red Bull TV, NASA TV), films du domaine public (Internet Archive, collection Feature Films, licence « Public Domain ») et films libres de la fondation Blender (Creative Commons BY).

Adresse à saisir dans Graal (Paramètres > Abonnements > Ajouter > Playlist M3U) :
https://code4wrld.github.io/Graal-releases/demo/graal-demo.m3u
